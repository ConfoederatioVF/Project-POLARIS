# POLARIS

Demographic research covering what is now modern-day Russia for the entirety of the Holocene. Part of [Velkscala](https://github.com/ConfoederatioVF/Velkscala) regional modelling. You can view reports here, but be warned they are synthetic and highly ephemeral, since this has to do with working papers and exploratory research: https://intellte.confoederatio.org/records/project_polaris/.

Settlement gazetteers are intended for [Stadestér](https://github.com/ConfoederatioVF/Stadester) and contain settlement population estimations by year and number of inhabitants.

## Datasets & Supplementary Materials

The following is a compiled list of datasets and supplementary materials made available digitally as part of POLARIS.
- [IA-RAS](https://github.com/CAD-Preserves/IA-RAS). Russian archaeological sites from 2,6M BC to 1925AD. Managed by _CAD-Preservés_.
